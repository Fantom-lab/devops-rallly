# Журнал использования ИИ

При выполнении DevOps-задания я использовал ChatGPT, чтобы разобраться с настройкой Docker, автоматизацией запуска приложения, работой с GitHub и исправлением возникающих ошибок. Предложенные команды я выполнял самостоятельно и проверял результат.

## 1. Изучение задания и подготовка проекта

**Запрос к ИИ:** Помочь разобраться в требованиях задания и определить, что необходимо сделать.

**Результат:** Составлен план работы. Подготовлены Dockerfile, docker-compose.yml и скрипт setup.sh.

**Мой комментарий:** Решил выполнять задание поэтапно, начиная с запуска приложения и заканчивая автоматическими проверками.

## 2. Настройка Docker

**Запрос к ИИ:** Помочь настроить многоэтапную сборку Docker, ограничения ресурсов и проверки состояния контейнеров.

**Результат:** Настроены Dockerfile и Docker Compose. Для запуска приложения используется непривилегированный пользователь, а для сервисов заданы ограничения ресурсов.

**Мой комментарий:** Разобрался, как запускать приложение и связанные сервисы через Docker Compose.

## 3. Исправление ошибок Docker Desktop

**Запрос к ИИ:** Помочь разобраться с проблемами Docker Desktop и WSL, из-за которых Docker Engine не запускался или сборка завершалась ошибкой.

**Что делал:** Проверял состояние Docker, настройки Docker Desktop и конфигурацию WSL. Разбирался с ошибками конфигурации daemon.json, проблемами доступа к файлам Docker и недоступностью Docker Engine.

**Результат:** После исправления проблем и повторного запуска Docker Desktop удалось восстановить работу Docker Engine. Сборка образов завершилась успешно.

**Мой комментарий:** Я понял, что ошибки сборки могут быть связаны не только с проектом, но и с самим Docker Desktop. Поэтому перед повторной сборкой проверял состояние Docker.

## 4. Автоматизация запуска приложения

**Запрос к ИИ:** Помочь написать setup.sh для автоматической настройки и запуска Rallly.

**Результат:** Скрипт проверяет необходимые команды, создаёт .env, генерирует секреты, собирает образы, запускает сервисы и проверяет доступность приложения.

**Мой комментарий:** Автоматический запуск оказался удобнее, чем выполнение всех команд вручную.

## 5. Работа с Git и GitHub

**Запрос к ИИ:** Помочь создать и настроить репозиторий GitHub, отправить проект и разобраться с ошибками Git.

**Результат:** Проект опубликован в репозитории https://github.com/Fantom-lab/devops-rallly. Настроена работа с удалённым репозиторием и веткой main.

**Мой комментарий:** Разобрался с командами git status, git log, git remote, git commit и git push. Также научился проверять, какие изменения ещё не сохранены в коммитах.

## 6. Настройка GitHub Actions

**Запрос к ИИ:** Помочь настроить CI и исправить ошибки автоматической проверки.

**Результат:** Создан workflow, который запускает setup.sh и smoke_test.sh. При настройке исправлена ошибка Invalid URL, связанная с отсутствующими переменными окружения. После изменений CI Pipeline завершился успешно.

**Мой комментарий:** Я понял, что для автоматической проверки необходимо правильно настроить окружение приложения.

## 7. Проверка приложения

**Запрос к ИИ:** Помочь проверить запуск приложения и доступность основных страниц.

**Результат:** Подготовлен smoke_test.sh для проверки главной страницы, страницы входа и создания опроса. Приложение удалось запустить локально по адресу http://localhost:3000.

**Мой комментарий:** Проверил состояние контейнеров и выполнение smoke-тестов. Это позволило убедиться, что основные компоненты запускаются и приложение отвечает на запросы.

## 8. Итоговая проверка

**Запрос к ИИ:** Помочь проверить проект на соответствие требованиям задания.

**Результат:** Проверены основные файлы, настройки Docker, запуск приложения, история коммитов и результат CI Pipeline. Обнаруженные недочёты были выделены для дополнительной проверки.

**Мой комментарий:** ИИ помогал разбираться в командах и ошибках, но работу с проектом и проверку результата я выполнял самостоятельно.
